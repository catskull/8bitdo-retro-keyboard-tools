8BitDo Retro Updater

Updates the Retro Keyboard (2dc8:5200) and Retro Keyboard Receiver (2dc8:5201) over WebHID. Unofficial, reverse-engineered from 8BitDo's dfu4.exe.

Use at your own risk. This is an unofficial tool, not made or supported by 8BitDo, and a failed update can leave a device unusable until it's reflashed. That said, it worked for me: a Retro Keyboard from 1.72 to 1.77 and two Retro Keyboard Receivers from 1.03 to 1.04, on macOS in Chrome.

Keep another input device handy: a keyboard or receiver can't type while it updates. If a receiver is left in bootloader mode (2dc8:5202), replug it, or run the update again if it failed after "Start updating".
